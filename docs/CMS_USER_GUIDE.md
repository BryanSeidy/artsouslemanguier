# Guide utilisateur — Sanity Studio (Art Sous Le Manguier)

Ce guide s’adresse à l’équipe éditoriale. Aucune connaissance technique n’est requise.

## 1. Accéder au Studio

Le Studio Sanity est accessible à l’adresse indiquée par votre administrateur (déployé sur Sanity Cloud ou en local à `http://localhost:3333`).

## 2. Tableau de bord

Le tableau de bord donne un accès rapide aux contenus : émissions, artistes, pages, projets, actualités et paramètres.

## 3. Ajouter une émission vidéo

Suivez ces étapes pour publier une nouvelle émission :

### Étape 1 — Ajouter une émission

Cliquez sur « Émissions » puis sur « Créer une émission ».

### Étape 2 — Coller le lien

Dans le champ **URL source**, collez le lien de la vidéo sur sa plateforme d’origine (YouTube, Vimeo, TikTok, etc.). Le lien doit commencer par `https://`.

Le système détecte automatiquement la plateforme et extrait l’identifiant de la vidéo.

### Étape 3 — Compléter la fiche

Remplissez les champs suivants :

- **Titre** — Titre complet de l’émission.
- **Description courte** — Résumé affiché sur la liste des archives.
- **Description complète** — Contenu éditorial détaillé.
- **Artiste** — Sélectionnez un artiste existant ou créez un nouveau profil.
- **Numéro d’épisode / Saison** — Si ces informations sont vérifiées.
- **Date de publication** — Date de mise en ligne originale.
- **Durée** — Durée de la vidéo (ex. : 23 min).
- **Orientation** — Paysage (16:9) ou portrait (9:16).
- **Couverture** — Image de couverture avec crédit.
- **Crédits** — Crédits de réalisation.
- **Mettre en vedette** — Cochez pour afficher l’émission en tête d’affiche sur l’accueil.
- **Ordre d’affichage** — Ordre dans les archives (0 = premier).
- **Statut de publication** — Brouillon ou Publié.

### Étape 4 — Prévisualiser

Vérifiez que la vignette, le titre et le format s’affichent correctement.

### Étape 5 — Publier

Cliquez sur « Publier ». L’émission devient visible dans les archives du site public.

## 4. Gérer les artistes

Dans « Artistes », vous pouvez créer un profil pour chaque artiste interviewé :

- Nom, biographie, discipline (peinture, sculpture, etc.)
- Portrait avec crédit
- Site web officiel (si disponible)

## 5. Gérer les pages institutionnelles

Dans « Pages institutionnelles », vous pouvez modifier les textes des pages « À propos », « Contact », etc.

## 6. Gérer les projets

Dans « Projets », décrivez les initiatives confirmées (ateliers, résidences, expositions).

## 7. Paramètres du site

Dans « Paramètres », configurez :

- Nom et description du site
- Logo de l’association
- Liens vers les réseaux sociaux officiels (vérifiés uniquement)
- Coordonnées officielles (courriel, téléphone, adresse — vérifiés uniquement)

## Règles importantes

- **Ne publiez jamais de contenu fictif.** Aucune date, durée ou titre inventé.
- **N’inventez pas de coordonnées.** Aucun e-mail, téléphone ou adresse non vérifié.
- **Utilisez uniquement des liens officiels.** HTTPS uniquement.
- **Le forfait gratuit Sanity a des datasets publics.** N’y stockez aucune information confidentielle.
